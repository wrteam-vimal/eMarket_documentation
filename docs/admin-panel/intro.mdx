# Introduction to eMarket Admin Panel

Welcome to the eMarket Admin Panel documentation. The admin panel is the web dashboard from which you run your
multi-vendor, multi-module store: **Grocery**, **Pharmacy**, **Ecommerce** and **Food Delivery**.

This section is the **setup guide**: what your server needs, how to install the panel with the web installer, and how
to configure each part of the store (store details, payments, login, Firebase, SMS, maps and more). For a
screen-by-screen reference of every menu, see the [Detailed Documentation](../detailed-documentation/intro.mdx).

![Dashboard](/img/detailed-documentation/dashboard.webp)

## What you manage from the panel

- Products, categories, attributes and stock, per module
- Orders, self pickup orders, return requests and abandoned carts
- Sellers, delivery boys, customers and their wallets
- Delivery cities and areas, delivery charges and time slots
- Payment methods, taxes and additional charges
- Home pages (Home Builder), promo codes, notifications and blogs
- Reports, languages, roles and system users
- Every configuration screen, from one **Settings** hub

## Installation in short

1. Check the [Server Requirements](./server-requirements.md) and apply the [PHP INI Settings](./php-ini-settings.md).
2. Optionally run the panel on its own [subdomain](./create-subdomain.md), for example `admin.yourdomain.com`.
3. Upload the files and open the **web installer** at `https://yourdomain.com/install` (see [Server Setup](./server-setup.md)),
   or install on your own computer (see [Localhost Setup](./localhost-setup.md)). The installer has five steps:
   **Welcome**, **Server requirements** (PHP version, PHP extensions and folder permissions), **Purchase code**,
   **Database & admin** (database connection plus the Super Admin email and password) and **All done**. It runs only
   once: after a successful install the install link is removed.
4. Log in at `/login` with the Super Admin account and follow [Configure eMarket](./configure-egroccer.md).

## The Settings hub

All configuration lives under **Settings** in the sidebar (**GENERAL** group, route `/system_settings`). The hub shows
every settings page as a card, grouped as **Store**, **Selling**, **Delivery**, **Apps & Website**,
**Content & Policies**, **Communication**, **Integrations** and **System**, with a **Search settings…** box at the top.
Cards such as **Store Setting**, **Login Setting** or **SMTP Mail Setting** open the matching section of **Store
Settings** (`/store_settings?section=...`). A role only sees the cards it has permission for.
